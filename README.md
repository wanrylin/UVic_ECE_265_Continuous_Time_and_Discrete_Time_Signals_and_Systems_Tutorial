## About This Repository

This repository contains supplementary materials for ECE 265 Tutorial T02. It is intended to help students review key ideas, prepare for tutorial sessions, and practice problem-solving strategies for continuous-time (CT) and discrete-time (DT) signals and systems.

As materials are added, they will be organized into two folders:

- `lecture-summaries/`: short reference summaries for selected lecture content.
- `tutorial-materials/`: tutorial handouts, practice questions, and MATLAB examples used or adapted for tutorial sessions.

This repository does not contain official assignment files, textbook or lecture-slide copies, protected solutions, or other instructor-provided course documents. Please obtain those materials from the official course website and Brightspace.

## Lecture Summaries

The lecture summaries are informal study references. They help organize ideas from lectures, connect examples to key concepts, and review important definitions or methods. They are not official course materials or a replacement for attending lectures and reading the textbook and slides. If there is any inconsistency, the instructor-provided materials take priority.

A typical tutorial handout may include:
